You are given two integers `n` and `k`. Return every possible combination of `k` distinct numbers chosen from the range `[1, n]`. You can return the combinations in any order.

Each combination should list its numbers in increasing order, and no two combinations may contain the same set of numbers.

## Examples

```text
Input:  n = 4, k = 2
Output: [[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
```

```text
Input:  n = 1, k = 1
Output: [[1]]
```

```text
Input:  n = 3, k = 3
Output: [[1,2,3]]
```

## Constraints

- 1 <= n <= 20
- 1 <= k <= n
