Given a string `s`, return a new string with its characters in reverse order. The last character becomes first, the second-to-last becomes second, and so on.

## Examples

```text
Input:  s = "hello"
Output: "olleh"
```

```text
Input:  s = "Racecar"
Output: "racecaR"        # reversal is case-sensitive
```

```text
Input:  s = "a"
Output: "a"
```

## Constraints

- 0 <= s.length <= 10^5
- `s` may contain any printable ASCII characters.

## Follow-up

Can you reverse the characters in place, using only O(1) extra space beyond the output?
