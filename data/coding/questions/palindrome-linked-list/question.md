You're given the head of a singly linked list. Decide whether the sequence of values it holds reads the same forwards and backwards, and return `true` or `false`.

## Examples

```text
Input:  head = [1, 2, 2, 1]
Output: true
```

```text
Input:  head = [1, 2, 3, 2, 1]
Output: true
```

```text
Input:  head = [1, 2, 3]
Output: false
```

## Constraints

- 1 <= number of nodes <= 10^5
- 0 <= Node.val <= 9

## Follow-up

Can you check it in O(n) time using only O(1) extra space?
