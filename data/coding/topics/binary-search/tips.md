- **Avoid overflow / off-by-one in mid:** use `lo + (hi - lo) / 2`, not `(lo + hi) / 2`. Decide upfront whether bounds are inclusive (`hi = len(arr) - 1`) or exclusive (`hi = len(arr)`) and stay consistent — mixing the two is the #1 source of infinite loops and skipped elements.
- **Loop condition matches bound style:** `while lo <= hi` for inclusive bounds, `while lo < hi` for exclusive. Getting this wrong causes an off-by-one or a loop that never terminates.
- **Define `condition(mid)` precisely before coding.** For "find leftmost true", condition should push `hi = mid - 1` on true and `lo = mid + 1` on false — write out a truth table for a 3-4 element example if unsure.
- **Rotated arrays:** at every midpoint, one half (`lo..mid` or `mid..hi`) is guaranteed sorted. Check which half is sorted first, then decide if the target lies inside that sorted half — this replaces the "is target bigger/smaller" logic used in plain binary search.
- **Binary search on the answer:** the "array" is implicit — it's the range `[min possible answer, max possible answer]`. Write a helper `can(x)` that answers "is `x` feasible?" in O(n) or better, confirm it's monotonic, then binary search over that range instead of the input array.
- **First/last occurrence:** don't stop at the first match. On finding `arr[mid] == target`, keep narrowing (`hi = mid - 1` for first, `lo = mid + 1` for last) and remember the last valid `mid` seen.
- **Pitfall — assuming sortedness implies uniqueness:** duplicates break the "which half is sorted" trick in rotated-array search (Search in Rotated Sorted Array II) — you may need to shrink both ends by one when `arr[lo] == arr[mid] == arr[hi]`.
- **Pitfall — non-monotonic predicate:** if `can(x)` isn't strictly monotonic, binary search silently gives a wrong answer with no crash — verify monotonicity on paper before coding.
- **Complexity check:** the outer loop is O(log n) iterations; if each iteration's `condition` check is O(n), total is O(n log n) — still usually a win over O(n²), but say so out loud.
